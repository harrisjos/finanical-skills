# Financial Skills Toolkit

A comprehensive financial education resource series covering essential money management skills and wealth-building strategies.

## About

This toolkit provides structured financial education materials designed for facilitators and includes:

- **10 Interactive Sessions** covering fundamental financial concepts
- **Facilitator Guides** with detailed instructions and talking points
- **Projector-Ready Presentations** for group sessions
- **Handouts and Worksheets** for practical exercises

## Sessions Overview

1. **Session 1**: The Wealth Mindset - Redefine wealth as Net Worth, not Income
2. **Session 2**: Creating Financial Goals
3. **Session 3**: Budgeting Basics
4. **Session 4**: Understanding Payslips
5. **Session 5**: Banking and Financial Products
6. **Session 6**: Debt Management
7. **Session 7**: Saving Strategies
8. **Session 8**: Investment Fundamentals
9. **Session 9**: Risk Management and Insurance
10. **Session 10**: Building a Side Hustle

## Usage

Visit the [live site](https://harrisjos.github.io/finanical-skills/) to access all materials.

Each session includes:
- **Facilitator Guide**: Detailed instructions for running the session
- **Projector Materials**: Visual aids for group presentation
- **Handouts**: Take-home materials and worksheets (where applicable)

## For Facilitators

This toolkit is designed to be used by financial education facilitators, trainers, and educators. Each session is structured to provide:

- Clear learning objectives
- Interactive activities
- Discussion prompts
- Practical exercises
- Take-home resources
